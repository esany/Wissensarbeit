# Domain Kernel

This directory is intentionally minimal in the template/reference implementation.

A concrete project grows a domain kernel only from actual work. It may contain concepts, methods, evidence rules, standards, controversies, specialist boundaries and project-specific synthesis. The system should discover required competencies and research current state of the art/best practice when material uncertainty warrants it.

The domain kernel must not become a static master prompt or universal ontology. It is durable, inspectable project knowledge that informs compiled AI contexts and human review.
